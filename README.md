# lecberg.github.io

Ryan Ma's AI workflow projects: **https://lecberg.github.io/**

Built with [Astro](https://astro.build) and Tailwind CSS. GitHub Actions builds and publishes the site on every push to `main`.

## Run it locally

```bash
npm install
npm run dev       # live-reloading dev server at http://localhost:4321
npm run build     # build to dist/
npm run preview   # serve the built site at http://localhost:4321
```

## Add or edit a project

Each project is one Markdown file in `src/content/projects/`. The front matter holds the card and header details (title, dates, stack, links, flow steps, figures, images). The body holds the "What I built" and "Keeping it reliable" sections. `order` sets the position on the home page.

Images go in `src/assets/<project>/`. Astro turns them into WebP at build time.

## Social preview image

`public/og.png` is generated by `node scripts/make-og.mjs`. Re-run it after changing the text in that script.
