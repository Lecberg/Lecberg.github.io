# lecberg.github.io

Ryan Ma's AI workflow projects: **https://lecberg.github.io/**

Built with [Astro](https://astro.build) and Tailwind CSS. GitHub Actions builds and publishes the site on every push to `main`.

## Run it locally

```bash
npm install
npm run dev       # live-reloading dev server at http://localhost:4321
npm run build     # build to dist/
npm run preview   # serve the built site at http://localhost:4321
```

## Add or edit a project

Each project is one Markdown file in `src/content/projects/`. The front matter holds the card and header details (title, dates, stack, links, flow steps, figures, images). The body holds the "What I built" and "Keeping it reliable" sections. `order` sets the position on the home page.

Images go in `src/assets/<project>/`. Astro turns them into WebP at build time.

## "Try it" panels

Each case study has a hands-on panel in `src/components/tryit/`, chosen by the `tryit` field in the project's front matter. Every panel loads its data from `public/data/` only when it scrolls into view.

| Panel | Data file | How the data was made |
|---|---|---|
| Traffic signs map | `tpdm-slice.json` | `node scripts/build-tpdm-slice.mjs` cuts the public sign survey down to four places. It checks that Mong Kok, 1 km, Stop gives 36. |
| PPP collection run | `ppp-run.json` | One run of the newsletter's collect step, made with `scripts/export-ppp-run.py`. Run it from an **empty folder with no `.env`**, so it can never reach the client's Google Sheet or Brevo. |
| CareerPilot replay | `careerpilot-run.json` | One real call to the live demo with the fictional `scripts/careerpilot/sample-cv.txt` and the Multiply Studio job ad (22 Nov 2026, 78 s). |

The maps use the Hong Kong Lands Department basemap. CARTO's basemaps now need an API key.
